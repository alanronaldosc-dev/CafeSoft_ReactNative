# Capturas para Google Play

Pendientes: no se incluyeron capturas simuladas ni pantallas inventadas.

Después de instalar el APK de preview, toma capturas reales con datos de prueba:

1. Inicio de sesión con el nombre e ícono definitivos.
2. Inicio del repartidor con opciones disponibles.
3. Listado o detalle de pedidos/cargas con datos de prueba.
4. Comprobación de conexión después de desplegar la API.

Puedes usar 1080 × 1920 px en orientación vertical si tu dispositivo o emulador permite ese formato. Conserva el contenido real y oculta datos personales. Verifica en Play Console las dimensiones y formatos admitidos para la categoría de dispositivo seleccionada.

El ícono `icono-512.png` sí está preparado. Las capturas solo se podrán marcar como evidencia de la HU cuando provengan de una ejecución real.
